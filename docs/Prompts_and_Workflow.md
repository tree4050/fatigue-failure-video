# 實際使用的 AI 提示詞、工具與製作流程

## 1. ChatGPT 收到的實際任務提示

本次內容與程式碼由 ChatGPT 依照使用者在本次對話提供的長篇規格製作。以下是原始提示中的逐字節錄，並非宣稱另行呼叫過某個影片模型：

> 請你同時擔任「材料科學教師、科學動畫導演與影片剪輯師」，製作一部適合大學工程科系學生觀看的疲勞破壞教學影片。
>
> 影片不能只是名詞介紹或文字投影片，必須透過真實照片、清楚的動畫與逐步解說，讓第一次接觸這個主題的學生理解疲勞破壞的原因、發展過程與工程意義。
>
> 影片題名：Fatigue Failure: From Small Cracks to Sudden Fracture
>
> 1. 總長度為 3 分鐘，包含片頭與參考來源。
> 2. 全程使用清楚、自然的英文旁白。
> 3. 提供與旁白一致且同步的英文字幕。
> 4. 至少包含一張有可靠來源的真實試件或疲勞斷面照片。
> 5. 包含裂紋起始、逐漸成長與最終斷裂的動畫。
> 6. 清楚解釋 S–N 曲線。
> 7. 清楚解釋斷裂韌性，以及它與裂紋尺寸、施加應力的關係。
> 8. 在影片中標示參考網站及照片出處。
> 9. 提供製作提示詞與實際使用的程式碼、工具和素材來源。
>
> 若使用單邊裂紋試件，a 表示從邊緣到裂紋尖端的長度。圖示與公式中的尺寸定義必須一致。
>
> 不得說裂紋只有在 K_I 達到 K_Ic 後才會開始疲勞成長；疲勞裂紋可以在低於此臨界值時逐漸成長。
>
> 如未實際建立 GitHub repository，請提供原始碼資料夾，不得虛構 GitHub 連結。

其餘原始要求按七個固定時段落實：0–15 秒開場、15–35 秒真實照片、35–65 秒裂紋動畫、65–105 秒 S–N 曲線、105–140 秒斷裂韌性、140–165 秒整合與工程意義、165–180 秒來源。完整成果以程式與分鏡為準。

## 2. 真正送入語音模型的文字與參數

Kokoro 接收的是**每句英文旁白本身**，不是另外的導演人設提示。全部實際輸入文字保存在 `assets/voice_clips/settings.json` 的 `text` 欄位；畫面字幕、英文原文與中文翻譯在 `src/lesson.py` 和 `assets/timeline.json`。

第一句實際輸入：

```text
Why can a metal part fail even when no single load is large enough to break it?
```

K_I / K_Ic 讀音的實際輸入範例：

```text
K eye describes crack tip loading: the Mode one stress intensity factor.
K eye see is material plane strain fracture toughness, not yield strength.
```

實際設定：Kokoro-82M v1.0、`af_heart`、`en-us`。基準合成速度 0.86；S–N 與斷裂韌性段落依實際合成長度調整到約 0.882 與 0.901。每句的精確數值、停頓參數及輸入字串均在 settings.json，沒有在成片中加速已生成的聲音。旁白為 AI 合成，未使用聲音複製。

## 3. 實際使用的工具

| 工具 | 實際用途 |
|---|---|
| ChatGPT | 理解作業規格、查核來源、撰寫英文講稿與中文翻譯、編寫與修正製作程式。 |
| 網頁搜尋與頁面讀取 | 查證真實照片、作者、年份、原始研究、授權及科學教學來源。 |
| Python 3.12 | 時間軸、程式動畫、文件與交付封裝。 |
| Kokoro-82M + kokoro-onnx + ONNX Runtime | 本機神經英文配音。 |
| Pillow + DejaVu fonts | 1920 × 1080 逐格向量風格畫面、真實照片置入與燒錄字幕。 |
| NumPy + SoundFile | 音訊拼接、淡入淡出、WAV 寫出及動畫幾何。 |
| FFmpeg / ffprobe | 24 fps H.264 / AAC MP4、音量正規化、完整解碼、長度與格式檢查。 |
| faster-whisper tiny.en | 自動語音辨識的輔助檢查；不是最終字幕的時間來源。 |

沒有使用影像生成模型冒充真實試件，沒有使用背景音樂，沒有實際建立 GitHub repository，也沒有上傳 YouTube。

## 4. 實際流程

1. 查核 UNSW、SOLIDWORKS 與 ASTM 公開教學／標準資訊，並找到 Wang Hui-li 和 Qin Si-feng 的原始論文 Figure 2。
2. 確認照片僅支持「螺栓疲勞斷面」及論文提供的螺紋根部背景；不推測照片上的精確裂紋起點和分區。
3. 編寫 355 個英文單字的旁白，分成 33 個字幕片段，保留七段固定時間。
4. 逐段實際合成 WAV，以實際樣本數計算字幕時間。句子間保留停頓，片尾留時間閱讀來源。
5. 用程式畫同一種單邊裂紋板試件，沿垂直方向施加拉力；裂紋由左邊緣水平向右成長。a 的圖示定義與公式一致。
6. 逐格繪製應力循環、裂紋延伸、快速分離、S–N 曲線與移動讀圖點，以及固定 a／固定應力的兩種 K_I 比較。
7. 使用 24 fps 寫出 4,320 格畫面。英文字幕直接畫在下方固定安全區，不依賴播放器開啟字幕。
8. 使用 FFmpeg 編成 H.264 / AAC MP4，將旁白正規化至約 −16 LUFS 目標，保留 180 秒完整時間。
9. 檢查分鏡樣張、字幕邊界、公式、單位、全部影格及音訊解碼。輸出使用獨立暫存檔後再原子替換，避免多次輸出同名檔時互相覆寫。
10. 整理原始碼、素材、字幕、雙語講稿、分鏡、來源和檢查結果。最終檢查數值見 QA 文件。

## 5. 可重現性

- 影片可直接以附上的照片、字型、時間軸和 narration.wav 重製，不需要模型下載。
- 若要修改配音，提供模型下載程式與 SHA-256 校驗值，以及全部英文輸入與逐句設定。
- 請先完成配音生成，再啟動影片輸出；不要在編碼期間覆寫 narration.wav 或時間軸。
- 重要命令與完整環境版本見 README.md 和 requirements 檔案。
